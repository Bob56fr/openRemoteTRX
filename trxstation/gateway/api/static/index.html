Connexion

Le mot de passe n'est jamais enregistré par cette page : utilise le gestionnaire de mots de passe de ton navigateur.

Deux notes descendantes : liaison perdue (répété pendant la reconnexion). Deux notes montantes : liaison rétablie, la station est en réception. Trois notes graves : reconnexion impossible. Le téléphone vibre aussi.

Le mot de passe est gardé en mémoire de la page le temps de la session (jamais enregistré) : il n'est pas redemandé pendant la reconnexion, mais il l'est après un rechargement de la page.

Page en HTTP : le navigateur bloque le micro (c'est une règle du navigateur, qu'aucune page ne peut contourner). La réception et les commandes fonctionnent. Pour émettre depuis ce navigateur :

  1. ouvre la station en HTTPS (certificat auto-signé : trx-setup --self-signed <adresse>), ou
  2. sur Chrome, ouvre chrome://flags/#unsafely-treat-insecure-origin-as-secure, active le réglage, ajoute exactement , puis relance Chrome.

Détails : docs/acces-distant.md.
