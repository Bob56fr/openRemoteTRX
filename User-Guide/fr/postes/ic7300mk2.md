# Fiche du poste : Icom IC-7300MK2

> **Validé sur un vrai poste** (statut public « validé », ★ GO et niveau 5 « complet » sur la page des postes,
> 2026-11-19) : commande, émission, son,
> page web, spectre HF par le second port et essais de panne, sous Windows et sous Debian 13. Ce qui reste à
> essayer est listé en fin de fiche. L'IC-7300 (premier modèle) est proche, mais n'a pas été essayé.

## Identité pour la station

| | |
|---|---|
| Numéro Hamlib | **3094** (« IC-7300MK2 ») ; il faut Hamlib **4.7 ou plus récent** (Debian 13 : installé par `install.sh`) |
| Liaison | **un seul câble USB** : commande (CI-V), son et second port |
| Ports série | deux ports : le **premier** pour la commande (Debian : `…-if00` dans `/dev/serial/by-id/` ; Windows : un COM), le **second** pour le spectre HF (Debian : `…-if02` ; Windows : un autre COM) |
| PTT | par **CAT** (CI-V) |
| Carte son | « **USB Audio Device** » (puce C-Media du poste ; sous Windows son nom commence par un chiffre qui change avec la prise USB) |
| Lu par la station | fréquence, mode, filtres, S-mètre, puissance, ALC, TOS, tension, split, RIT / ΔTX, VOX, réglages du coupleur, **TOT du poste** |
| Pas disponible | VFO actif (A, B, mémoire) ; température du poste (le seuil de température de la station est sans effet) |

## Pilote USB (Windows)

Installe le pilote **« Icom USB Driver » version 1.80 ou plus récente** depuis le site d'Icom, câble débranché,
puis branche le poste. La version 1.70 fige Chrome et Edge quand une page lit le port série (Autotest). Sous Debian :
aucun pilote.

## Menus à régler

### Liaison : MENU > SET > Connectors

| Menu | Valeur | Pourquoi |
|---|---|---|
| CI-V > CI-V Baud Rate | le **même débit** que dans l'assistant | sinon le poste ne répond pas |
| MOD Input > **DATA MOD** | **USB** | la voix arrive par l'USB ; la station n'émet qu'en **mode données** (USB-D / LSB-D) |
| USB SEND, USB Keying (CW), USB Keying (RTTY) | **OFF** | aucune ligne du port USB ne doit pouvoir mettre le poste en émission |
| USB MOD Level | à ajuster (partie 3) | niveau de la voix qui arrive par l'USB : à régler avec l'ALC |

Le poste n'accepte l'USB que dans DATA MOD **ou** DATA OFF MOD. Avec le second port réglé (menu 2.7), la station
vérifie DATA MOD à chaque connexion et te prévient s'il n'est pas sur USB.

### Sécurités : MENU > SET > Function

| Menu | Valeur | Pourquoi |
|---|---|---|
| **Time-Out Timer (CI-V)** | **3 min** | dernière barrière, dans le poste lui-même ; la station le relit à chaque connexion d'un opérateur et te prévient s'il est sur OFF |
| Tuner > [TUNER] Switch | **Auto** | coupleur intégré : état mémorisé par bande |
| Tuner > PTT Start | **ON** | accord lancé tout seul à la première émission sur une nouvelle fréquence |

La station vérifie les réglages du coupleur à chaque connexion (si tu as répondu « oui » à sa question dans
l'assistant), sans jamais les changer.

### Autres réglages conseillés

| Réglage | Valeur | Pourquoi |
|---|---|---|
| Touche **VOX** | éteinte | la station la coupe à chaque connexion d'un opérateur ; sur ce poste, l'état du VOX dépend du mode (coupé en mode données, encore en marche en phonie) |
| Puissance (RF POWER, bouton MULTI) | la puissance que tu t'autorises | plafond du poste lui-même |
| Split | à la **touche SPLIT** du poste | la station ne l'écrit jamais : elle le lit et refuse d'émettre si la fréquence d'émission sort de tes bandes |

## Son sous Windows

Paramètres > Son : la sortie « USB Audio Device » du poste **à 100 %**, améliorations désactivées ; le niveau
d'émission se dose par **USB MOD Level** dans le poste. Une sortie à volume réduit donne une émission sans
puissance. La carte du poste ne doit jamais être le son par défaut du PC (partie 1).

## Spectre HF par le second port

Menu **2.7** d'openRemoteTRX Console : choisis le **second** port du poste. La station y lit l'écran du poste
(spectre HF de la page et de l'application) et les préréglages de filtre FIL1/2/3. Le spectre se **fige pendant
l'émission** : c'est le poste qui s'arrête de l'envoyer, pas une panne.

## Correspondance des modes

| Page web / Hamlib | Écran de l'IC-7300MK2 |
|---|---|
| USB / LSB | USB / LSB (réception ; émission refusée : la voix passe par les modes données) |
| PKTUSB / PKTLSB | USB-D / LSB-D |
| FM / PKTFM | FM / FM-D |
| AM / CW / RTTY | AM / CW / RTTY |

## Points encore à essayer

- Allumage et extinction à distance (menu 2.8) : un IC-7300MK2 éteint refuse la lecture de son alimentation ; à
  essayer sur ton poste avant de compter dessus.
- Émission au micro du poste avec la station en marche (essai 6 de la partie 3.5).
