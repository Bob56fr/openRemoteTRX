# Datenblatt des Transceivers: Icom IC-7300MK2

> **An einem echten Gerät validiert** (öffentlicher Status „validiert“, ★ GO und Stufe 5 „vollständig“ auf der Seite
> der Transceiver, 2026-11-19): Steuerung, Senden, Ton,
> Webseite, KW-Spektrum über den zweiten Port und Ausfalltests, unter Windows und unter Debian 13. Was noch zu testen
> ist, steht am Ende des Datenblatts. Der IC-7300 (erstes Modell) ist ähnlich, wurde aber nicht getestet.

## Identität für die Station

| | |
|---|---|
| Hamlib-Nummer | **3094** („IC-7300MK2“); nötig ist Hamlib **4.7 oder neuer** (Debian 13: von `install.sh` installiert) |
| Verbindung | **ein einziges USB-Kabel**: Steuerung (CI-V), Ton und zweiter Port |
| Serielle Ports | zwei Ports: der **erste** für die Steuerung (Debian: `…-if00` in `/dev/serial/by-id/`; Windows: ein COM), der **zweite** für das KW-Spektrum (Debian: `…-if02`; Windows: ein anderer COM) |
| PTT | über **CAT** (CI-V) |
| Soundkarte | „**USB Audio Device**“ (C-Media-Chip des Transceivers; unter Windows beginnt ihr Name mit einer Ziffer, die sich mit der USB-Buchse ändert) |
| Von der Station gelesen | Frequenz, Betriebsart, Filter, S-Meter, Leistung, ALC, SWR, Spannung, Split, RIT / ΔTX, VOX, Einstellungen des Tuners, **TOT des Transceivers** |
| Nicht verfügbar | aktiver VFO (A, B, Speicher); Temperatur des Transceivers (die Temperaturschwelle der Station ist wirkungslos) |

## USB-Treiber (Windows)

Installieren Sie den Treiber **„Icom USB Driver“ Version 1.80 oder neuer** von der Website von Icom, Kabel
abgezogen, dann schließen Sie den Transceiver an. Die Version 1.70 lässt Chrome und Edge hängen, wenn eine Seite den
seriellen Port liest (Autotest). Unter Debian: kein Treiber.

## Einzustellende Menüs

### Verbindung: MENU > SET > Connectors

| Menü | Wert | Warum |
|---|---|---|
| CI-V > CI-V Baud Rate | **dieselbe Baudrate** wie im Assistenten | sonst antwortet der Transceiver nicht |
| MOD Input > **DATA MOD** | **USB** | die Stimme kommt über USB; die Station sendet nur in einer **Datenbetriebsart** (USB-D / LSB-D) |
| USB SEND, USB Keying (CW), USB Keying (RTTY) | **OFF** | keine Leitung des USB-Ports darf den Transceiver auf Senden schalten können |
| USB MOD Level | anzupassen (Teil 3) | Pegel der über USB ankommenden Stimme: mit der ALC einzustellen |

Der Transceiver akzeptiert USB nur in DATA MOD **oder** DATA OFF MOD. Ist der zweite Port eingerichtet (Menü 2.7),
prüft die Station DATA MOD bei jeder Verbindung und warnt Sie, wenn es nicht auf USB steht.

### Sicherheiten: MENU > SET > Function

| Menü | Wert | Warum |
|---|---|---|
| **Time-Out Timer (CI-V)** | **3 min** | letzte Barriere, im Transceiver selbst; die Station liest ihn bei jeder Verbindung eines Operators und warnt Sie, wenn er auf OFF steht |
| Tuner > [TUNER] Switch | **Auto** | eingebauter Tuner: Zustand je Band gespeichert |
| Tuner > PTT Start | **ON** | Abstimmung startet von selbst beim ersten Senden auf einer neuen Frequenz |

Die Station prüft die Einstellungen des Tuners bei jeder Verbindung (wenn Sie ihre Frage im Assistenten mit „ja“
beantwortet haben), ohne sie je zu ändern.

### Weitere empfohlene Einstellungen

| Einstellung | Wert | Warum |
|---|---|---|
| Taste **VOX** | aus | die Station schaltet es bei jeder Verbindung eines Operators ab; bei diesem Gerät hängt der Zustand des VOX von der Betriebsart ab (aus in der Datenbetriebsart, noch eingeschaltet in Telefonie) |
| Leistung (RF POWER, Knopf MULTI) | die Leistung, die Sie sich erlauben | Obergrenze des Transceivers selbst |
| Split | mit der **Taste SPLIT** des Transceivers | die Station schreibt ihn nie: Sie liest ihn und verweigert das Senden, wenn die Sendefrequenz außerhalb Ihrer Bänder liegt |

## Ton unter Windows

Einstellungen > Sound: der Ausgang „USB Audio Device“ des Transceivers **auf 100 %**, Verbesserungen deaktiviert; der
Sendepegel wird über **USB MOD Level** im Transceiver dosiert. Ein Ausgang mit reduzierter Lautstärke ergibt ein
Senden ohne Leistung. Die Karte des Transceivers darf nie das Standard-Audiogerät des PCs sein (Teil 1).

## KW-Spektrum über den zweiten Port

Menü **2.7** von openRemoteTRX Console: Wählen Sie den **zweiten** Port des Transceivers. Die Station liest dort den
Bildschirm des Transceivers (KW-Spektrum der Seite und der App) und die Filtervoreinstellungen FIL1/2/3. Das Spektrum
**friert während des Sendens ein**: Der Transceiver hört auf, es zu senden, das ist kein Ausfall.

## Zuordnung der Betriebsarten

| Webseite / Hamlib | Display des IC-7300MK2 |
|---|---|
| USB / LSB | USB / LSB (Empfang; Senden abgelehnt: die Stimme geht über die Datenbetriebsarten) |
| PKTUSB / PKTLSB | USB-D / LSB-D |
| FM / PKTFM | FM / FM-D |
| AM / CW / RTTY | AM / CW / RTTY |

## Noch zu testende Punkte

- Ein- und Ausschalten aus der Ferne (Menü 2.8): Ein ausgeschalteter IC-7300MK2 verweigert das Auslesen seiner
  Stromversorgung; an Ihrem Gerät testen, bevor Sie sich darauf verlassen.
- Senden mit dem Mikrofon des Transceivers bei laufender Station (Test 6 aus Teil 3.5).
