# Transceiver sheet: Icom IC-7300MK2

> **Validated on a real transceiver** (public status “validated”, ★ GO and level 5 “complete” on the transceivers page,
> 2026-11-19): control, transmission, audio,
> web page, HF spectrum through the second port and failure tests, on Windows and on Debian 13. What remains to be
> tested is listed at the end of the sheet. The IC-7300 (first model) is close, but has not been tested.

## Identity for the station

| | |
|---|---|
| Hamlib number | **3094** (“IC-7300MK2”); requires Hamlib **4.7 or newer** (Debian 13: installed by `install.sh`) |
| Link | **a single USB cable**: control (CI-V), audio and second port |
| Serial ports | two ports: the **first** for control (Debian: `…-if00` in `/dev/serial/by-id/`; Windows: one COM), the **second** for the HF spectrum (Debian: `…-if02`; Windows: another COM) |
| PTT | by **CAT** (CI-V) |
| Sound card | “**USB Audio Device**” (the transceiver's C-Media chip; on Windows its name starts with a digit that changes with the USB socket) |
| Read by the station | frequency, mode, filters, S-meter, power, ALC, SWR, voltage, split, RIT / ΔTX, VOX, tuner settings, **transceiver TOT** |
| Not available | active VFO (A, B, memory); transceiver temperature (the station's temperature threshold has no effect) |

## USB driver (Windows)

Install the **“Icom USB Driver” version 1.80 or newer** from the Icom website, cable unplugged,
then plug in the transceiver. Version 1.70 freezes Chrome and Edge when a page reads the serial port (Autotest). On Debian:
no driver.

## Menus to set

### Link: MENU > SET > Connectors

| Menu | Value | Why |
|---|---|---|
| CI-V > CI-V Baud Rate | the **same speed** as in the wizard | otherwise the transceiver does not respond |
| MOD Input > **DATA MOD** | **USB** | the voice arrives through USB; the station transmits only in **data mode** (USB-D / LSB-D) |
| USB SEND, USB Keying (CW), USB Keying (RTTY) | **OFF** | no line of the USB port must be able to put the transceiver into transmission |
| USB MOD Level | to adjust (part 3) | level of the voice arriving through USB: to set with the ALC |

The transceiver accepts USB only in DATA MOD **or** DATA OFF MOD. With the second port set (menu 2.7), the station
checks DATA MOD at each connection and warns you if it is not on USB.

### Safety: MENU > SET > Function

| Menu | Value | Why |
|---|---|---|
| **Time-Out Timer (CI-V)** | **3 min** | last barrier, in the transceiver itself; the station reads it again at each operator connection and warns you if it is OFF |
| Tuner > [TUNER] Switch | **Auto** | built-in tuner: state stored per band |
| Tuner > PTT Start | **ON** | tuning started by itself at the first transmission on a new frequency |

The station checks the tuner settings at each connection (if you answered “yes” to its question in
the wizard), without ever changing them.

### Other recommended settings

| Setting | Value | Why |
|---|---|---|
| **VOX** key | off | the station switches it off at each operator connection; on this transceiver, the VOX state depends on the mode (off in data mode, still on in phone) |
| Power (RF POWER, MULTI knob) | the power you allow yourself | ceiling of the transceiver itself |
| Split | with the transceiver's **SPLIT key** | the station never writes it: it reads it and refuses to transmit if the transmit frequency leaves your bands |

## Audio on Windows

Settings > Sound: the transceiver's “USB Audio Device” output **at 100 %**, enhancements disabled; the transmit
level is set with **USB MOD Level** in the transceiver. An output at reduced volume gives a transmission without
power. The transceiver's card must never be the PC's default sound (part 1).

## HF spectrum through the second port

Menu **2.7** of openRemoteTRX Console: choose the transceiver's **second** port. The station reads the transceiver's screen there
(HF spectrum of the page and of the application) and the FIL1/2/3 filter presets. The spectrum **freezes during
transmission**: the transceiver stops sending it, it is not a fault.

## Mode mapping

| Web page / Hamlib | IC-7300MK2 screen |
|---|---|
| USB / LSB | USB / LSB (receive; transmission refused: the voice goes through the data modes) |
| PKTUSB / PKTLSB | USB-D / LSB-D |
| FM / PKTFM | FM / FM-D |
| AM / CW / RTTY | AM / CW / RTTY |

## Points still to test

- Remote power on and off (menu 2.8): a switched-off IC-7300MK2 refuses the reading of its power state; to
  test on your transceiver before relying on it.
- Transmission with the transceiver microphone while the station is running (test 6 of part 3.5).
