Échelle : redémarrer passerelle, rigctld, reset USB, reboot (limité), puis MODE SÛR (`trx-supervisor --clear-safe-mode`). 118 tests dont un de bout en bout avec vrais processus (SIGSTOP, POSIX seulement).
