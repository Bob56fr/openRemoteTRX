Station settings: station.toml

openRemoteTRX version 0.297.0

station.toml is the station configuration file: the transceiver, the sound cards, the network, the transmit safety rules, the accounts, the optional features. It is written by the openRemoteTRX Console wizard and is then changed through openRemoteTRX Console (menu 8.1, and the dedicated menus given for each section). The station checks it at every start: an inconsistent value is refused with a precise message, never silently ignored.

Beginner: only the common settings concern you; the wizard sets them for you. The expert settings have safe default values: only touch them if you know what you are doing. File location: /etc/trx-remote/station.toml (Debian, Raspberry Pi), C:\ProgramData\trx-remote\station.toml (Windows).

The transceiver [rig]

The transceiver controlled through Hamlib: model, CAT link, PTT control, modes and power.

Changed with: Wizard (menu 2.1), transceiver profiles (menu 2.3), or menu 8.1. — applied when the station restarts (openRemoteTRX Console offers to do it).

model common
What it does
Transceiver model number in Hamlib (list: rigctl -l). 1 = dummy transceiver, to try without hardware.
Default
0
Example
IC-7300MK2: 3094 (Hamlib 4.7).
port common
What it does
Serial port of the CAT link. Under Linux, prefer the stable name /dev/serial/by-id/… (it does not change from one restart to the next).
Default
""
Example
Windows: COM8; Linux: /dev/serial/by-id/usb-Silicon_Labs_…-if00-port0.
speed common
What it does
Serial speed of the CAT link. Empty: Hamlib's default speed for this model. Must match the transceiver setting.
Default
empty
Example
19200, 115200.
ptt_type common
What it does
How the station keys the transceiver: RIG (CAT command), RTS or DTR (line of a serial port), GPIO / GPION (Raspberry Pi pin), NONE (none: receive only).
Default
"RIG"
Safety
The station reads the PTT state back after every command; with NONE, no transmission is possible.
ptt_port expert
What it does
Port of the PTT control when it is not on the CAT port (RTS or DTR of another port). Empty: the CAT port.
Default
""
extra_conf expert
What it does
Extra options passed to rigctld (-C name=value), for a transceiver that needs them.
Default
[]
Example
["civaddr=0x94"]
Safety
Forbidden here: the spectrum options (async, multicast_…, set by [spectrum]) and cache_timeout. The station always starts rigctld with cache_timeout=0 (since 0.134.0): with a cache, after a cut rigctld returns the commanded value instead of the real state of the transceiver, and a transceiver still transmitting would look as if it had stopped.
tx_modes common
What it does
Modes in which transmitting is allowed; empty = all. On Icom transceivers, audio from the USB sound card is only transmitted in data modes (USB-D, LSB-D, FM-D…): in another mode, the transceiver would modulate with its own microphone.
Default
[]
Example
Icom: ["PKTUSB", "PKTLSB", "FM-D", "AM-D"].
Safety
A transmit request in a mode missing from the list is refused. The SWR measurement uses the first FM mode allowed here (FM, PKTFM or FM-D).
max_power_w common
What it does
Maximum power of the transceiver in watts. 0: unknown, the page and the app show percentages instead of watts.
Default
0
Example
100 for a 100 W transceiver.
tuner common since 0.210.0
What it does
The transceiver's built-in antenna tuner is used. At each operator connection, the station then reads the transceiver's automatic tuning settings through the second CI-V port (IC-7300MK2: [TUNER] Switch = Auto, PTT Start = ON) and warns if they are wrong or cannot be checked. It never changes them.
Default
false
Example
true if the antenna goes through the transceiver's tuner; false (default) otherwise.
Safety
Remotely, without automatic tuning when keying, a new frequency may transmit into a high SWR. Outside the amateur bands, tuning on PTT is not guaranteed by the transceiver.
port_usb expert since 0.222.0
What it does
USB identity of the transceiver port (manufacturer, product, serial number, interface), recorded when remote power-on is enabled. Before each power-on, the station checks that the port in port is STILL the transceiver's; if it has changed (another USB socket under Windows), power-on is refused and the new port is named.
Default
""
Example
10C4:EA70 SN=01D0F21E IF=00 (“Enhanced” port of the CP2105 of an FTDX10); empty = not recorded.
Safety
The station only READS this identity; it never opens another port on its own initiative (a serial port opened by mistake can raise RTS or DTR, hence a PTT).
ptt_port_usb expert since 0.222.0
What it does
USB identity of the PTT port when it is separate from the transceiver port (PTT by RTS or DTR); same check as port_usb.
Default
""
Example
Empty (default): PTT over CAT, or port not recorded.

Audio [audio]

The two audio directions between the station and the transceiver (audio interface such as Digirig, SignaLink, or the transceiver's USB sound card).

Changed with: Wizard (menu 2.1), transceiver profiles (menu 2.3), or menu 8.1. — applied when the station restarts (openRemoteTRX Console offers to do it).

capture_device common
What it does
Sound card that receives the audio from the transceiver (the audio heard remotely). Empty: the system default card.
Default
""
Example
Linux: plughw:CARD=CODEC,DEV=0; Windows: Microphone (USB Audio CODEC).
playback_device common
What it does
Sound card that sends audio to the transceiver (your voice when transmitting). Empty: the system default card.
Default
""
sample_rate expert
What it does
Sample rate. Only 48,000 is supported (Opus codec).
Default
48000
Values
48000 only.
rx_gain_db common
What it does
Gain applied to the received audio, in dB (negative = quieter), for all terminals, visitors and broadcast included. Set by openRemoteTRX Console, menu 2.9, which suggests a value based on the received level.
Default
0.0
Values
-40 to +20 dB.
rx_limiter common since 0.227.0
What it does
Limiter of the received audio: peaks capped at -1 dBFS before the terminals, so that a high gain or a strong signal does not clip. false = gain applied without a cap (clipping possible), for troubleshooting only. openRemoteTRX Console, menu 2.9.
Default
true
Example
rx_limiter = true
tx_gain_db common
What it does
Gain applied to the audio sent to the transceiver, in dB.
Default
0.0
Safety
Too much overdrives the transmitter: set it on a dummy load while watching the ALC.

Network [network]

How the web page and the app reach the station. See also the remote access guide (VPN or exposed port with HTTPS).

Changed with: Wizard (menu 2.1), phone pairing (menu 4.1), or menu 8.1. — applied when the station restarts (openRemoteTRX Console offers to do it).

rigctld_host expert
What it does
Listening address of rigctld, the Hamlib service that talks to the transceiver.
Default
"127.0.0.1"
Safety
rigctld has NO authentication: it must listen locally only (127.0.0.1). The station refuses any other value.
rigctld_port expert
What it does
Local port of rigctld.
Default
4532
gateway_bind common
What it does
Listening address of the station for the page and the app. 127.0.0.1: this machine only; the machine's address on your VPN; or 0.0.0.0: all its addresses.
Default
"127.0.0.1"
Safety
Outside the machine, HTTPS is required (tls_cert, tls_key), except with allow_insecure_http inside a VPN.
gateway_port common
What it does
Station port for the web page and the app.
Default
8443
web_client expert
What it does
Serves the web control page on the same port as the app. false: app only.
Default
true
tls_cert common
What it does
HTTPS certificate of the station (PEM file). The wizard generates one; its fingerprint is used to pair the phone (menu 4.1).
Default
""
tls_key common
What it does
Private key of the HTTPS certificate.
Default
""
Safety
Secret file: it must be readable by the station only.
allow_insecure_http expert
What it does
Allows listening outside the machine WITHOUT HTTPS. Only accept this inside a VPN that already encrypts everything.
Default
false
Safety
On the Internet without a VPN, passwords and audio would travel unencrypted: leave false.
trusted_proxies expert
What it does
Addresses (or ranges) of the trusted relays in front of the station, whose X-Forwarded-For header is believed to know the client's real address.
Default
["127.0.0.1", "::1"]
ice_servers expert
What it does
STUN/TURN servers to set up audio (WebRTC) across the Internet. []: local network or VPN only.
Default
["stun:stun.l.google.com:19302"]

Transmit safety [safety]

The rules the station applies to EVERY transmission requested remotely, independently of the page and the app.

Changed with: Menu 8.1; temperature thresholds: menu 3.1; replay: wizard (menu 2.1). — applied when the station restarts (openRemoteTRX Console offers to do it).

tot_s common
What it does
Maximum duration of a transmission (TOT) in seconds: beyond it, the station goes back to receive, with a warning beep beforehand.
Default
90
Values
Above 0 and at most tot_ceiling_s.
Safety
Also limits the length of a replayed recording (TOT minus 5 s).
tot_ceiling_s common
What it does
TOT ceiling: the value of tot_s cannot exceed it.
Default
120
Safety
The supervisor cuts on its own side beyond [supervisor] tot_abs_s, which must stay larger.
enforce_bands common
What it does
true: the station refuses to transmit outside the [[bands]]. false: the transceiver forbids it (for example the “TX limit” of Icom transceivers); the responsibility is yours.
Default
true
Safety
With true and an empty band list, no transmission is possible (receive only).
warn_before_s expert
What it does
Seconds before the end of the TOT when the warning is given.
Default
10
Values
Between 0 and tot_s.
heartbeat_interval_ms expert
What it does
Expected rate of heartbeats from the phone or the page during a transmission (proof that the client is still there).
Default
500
heartbeat_timeout_ms expert
What it does
With no heartbeat for this long, the station goes back to receive (client lost, network down).
Default
2000
Safety
Do not increase it without a reason: this is what cuts a transmission whose client has disappeared.
rig_temp_warn_c common
What it does
Transceiver temperature (if Hamlib provides it) from which a warning is shown and sent.
Default
40
Values
Between 20 and 90 °C, lower than rig_temp_cut_c.
rig_temp_cut_c common
What it does
Beyond it, remote transmission is cut and refused until the temperature is back below rig_temp_warn_c.
Default
50
allow_replay common since 0.91.0
What it does
Allows replaying a recording of the received audio (page and app): record a correspondent then send it back on transmit. Asked by the wizard when the transceiver is added; refused by default.
Default
false
Safety
Retransmitting a station's transmission to third parties is generally FORBIDDEN in the amateur service: only enable it knowingly, under your own responsibility.
swr_alert common since 0.212.0
What it does
SWR above which the station warns the operator who is transmitting (red banner and beep in the page), if the SWR read stays above it for more than one second; one alert per transmission. 0: off.
Default
2.0
Values
0, or 1.2 to 10.
Example
2.0 (default).
Safety
Alert ONLY: the station never cuts the transmission for a high SWR (the transceiver already reduces its power by itself).
rig_tot_warn common since 0.245.0
What it does
Transceiver TOT (internal transmit timer) READ when an operator connects: if it is OFF, the page and the app say so, once a day per account. Only for a transceiver whose reading has been qualified (currently the Icom IC-7300MK2, PTT over CAT); for the others, the wizard reminds you to set it.
Default
true
Example
true (default).
Safety
READ only: the station never changes the transceiver TOT and does not prevent transmitting. An uncertain reading (silent transceiver, unexpected answer) never gives “OFF”: no notice.

Accounts [[clients]]

One entry per account that can connect: operators (full control) and visitors (listen only).

Changed with: Wizard (menu 2.1), visitors (menu 4.2), command trx-setup --add-client. — read again by the station within seconds, no restart needed.

id common
What it does
Login username of the account, typed in the page or the app. Since 0.247.0, case does not matter when logging in (“PC” opens the account “pc”): two accounts that differ only by case are refused.
Default
""
Example
"telephone", "voiture"
token expert
What it does
Old plain-text secret (older versions). Still accepted, but to be replaced by a password (password_hash).
Default
""
Safety
A plain-text secret in the file can be read by anyone who reads the file: replace it.
password_hash common
What it does
Password hash (scrypt); never the password itself. Written by the wizard, menu 4.2 or trx-setup --set-password.
Default
""
role common
What it does
operator: full control; listener: listen-only visitor, no command to the transceiver.
Default
"operator"
pseudo common
What it does
Name shown to the other connected users instead of the username (several accounts can use the same one).
Default
""
enabled common
What it does
false: connection refused, and a current connection is closed.
Default
true
expires common
What it does
End date of the account (YYYY-MM-DD, station time); empty: never.
Default
""
admin common since 0.178.0
What it does
true: this operator account can also open openRemoteTRX Console over the network ([remote_console], menu 4.6). Other operators control the transceiver but do not administer the station.
Default
false
Values
Operators only (never a visitor).
Safety
The password of an administrator account opens the station configuration: do not lend it.

Powering the transceiver on and off remotely [power]

Power the transceiver on when an operator connects and power it off from the page or the app (STOP held for 3 s). Off by default. Only for a transceiver that allows it over CAT (Hamlib: “set / get Power Stat”) and keeps its USB powered once switched off. The station never transmits to power the transceiver on or off.

Changed with: openRemoteTRX Console, menu 2.8 (enabling with a power off / power on test); fine settings: menu 8.1. — applied when the station restarts (openRemoteTRX Console offers to do it).

enabled common since 0.222.0
What it does
true: transceiver powered on when an operator connects and powered off from the page or the app. false (default): no remote power on or off.
Default
false
Example
Enable through menu 2.8 of openRemoteTRX Console, which first tries to power the transceiver off and on again.
Safety
Power-off refused during any transmission and when the transceiver is used on site; after a power-on, the station reads the PTT back and puts the transceiver back in receive if it came on transmitting.
on_timeout_s expert since 0.222.0
What it does
Wait for the transceiver to answer after the power-on order. Beyond it, power-on is reported as failed with a clear message.
Default
30
Values
5 to 120 s (default 30; an FTDX10 answers in about 8 s).
idle_off common since 0.222.0
What it does
Automatic power-off of the transceiver when nobody has been connected (neither operator nor visitor) for idle_off_hours hours, with no broadcast running and no action on the transceiver. Postponed by 10 min during a transmission, never forced.
Default
false
Example
false (default).
idle_off_hours common since 0.222.0
What it does
Time without any connection before the automatic power-off.
Default
4
Values
1 to 168 h (default 4).
notify common since 0.222.0
What it does
ntfy alert at each power-on, power-off or failure (who, how). A transceiver that comes on TRANSMITTING always sends an alert, even without this setting.
Default
false
Example
false (default); requires [supervisor] notify_url.

Breizh Audio Box in the transmit path [breizh]

The microphone audio goes through Breizh Audio Box (voice processing) on another PC of the local network before reaching the transceiver. If Breizh stops answering, the station switches back to direct by itself. The microphone audio travels UNENCRYPTED on the local network: only on a trusted network.

Changed with: Menu 8.1; the pairing key is created with openRemoteTRX Console (file breizh.key next to station.toml). — applied when the station restarts (openRemoteTRX Console offers to do it).

enabled common since 0.99.0
What it does
true: the operator's microphone audio goes through Breizh Audio Box during transmission, when Breizh answers.
Default
false
Safety
Breizh can never start or extend a transmission: the station keeps the PTT, the transmit audio gate and its limiter.
host common since 0.99.0
What it does
IP address of the PC running Breizh Audio Box (127.0.0.1 if it is the same PC).
Default
""
Values
Private IP address only (RFC 1918: 10/8, 172.16/12, 192.168/16; link-local 169.254/16; loopback 127/8; IPv6 fd00::/8, fe80::/10). Neither a host name nor a public address.
Safety
The microphone audio is not encrypted: a public address is refused.
port expert since 0.99.0
What it does
UDP port on which Breizh waits for the station (the same as in Breizh's “OpenRemoteTRX” tab).
Default
47100
Values
1024 to 65535.
key_file expert since 0.99.0
What it does
File with the pairing key shared with Breizh. Empty: breizh.key next to station.toml. The key is never written in station.toml.
Default
""
Safety
File refused if it is readable by all accounts.
block_timeout_ms expert since 0.99.0
What it does
Delay beyond which an audio block (10 ms) that has not come back from Breizh is sent unprocessed, at reduced gain.
Default
40
Values
15 to 100 ms.
lost_ms expert since 0.99.0
What it does
With no return at all from Breizh for this long, the transmission continues direct until it ends (fallback).
Default
100
Values
50 to 500 ms, larger than block_timeout_ms.
fallback_gain_db expert since 0.99.0
What it does
Gain of the direct audio during a fallback (Breizh lost), so as not to overmodulate with audio meant to be processed.
Default
-6.0
Values
-20 to 0 dB.
reactivate_after_s expert since 0.99.0
What it does
After a fallback, time during which Breizh must answer without fault before being used again automatically (never during a transmission). 0: only when the operator asks for it.
Default
60
Values
0, or 30 to 3600 s.

Changed with: Menu 8.1. The indicator thresholds chosen in the page or the app (statistics, “Thresholds” section) are stored separately and take precedence over the ones here. — applied when the station restarts (openRemoteTRX Console offers to do it).

Group presence [presence]

A group of friends using openRemoteTRX sees who is active on their station and, if each one agrees, on which frequency and in which mode. A relay on the Internet carries ENCRYPTED states that it cannot read. The “presence” module has no right over the transceiver: it can neither transmit nor change frequency; a QSY to a friend only happens when the operator taps it, in receive.

Changed with: Menu 8.1, and add “presence” to [modules] run. Groups, nickname and what is shared are set in the page, the app or openRemoteTRX Console (stored separately, not in station.toml). — applied when the station restarts (openRemoteTRX Console offers to do it).

enabled common since 0.117.0
What it does
true: the station registers with the relay and exchanges presence with the groups it belongs to (“presence” must also be in [modules] run).
Default
false
Safety
Presence only shows: no data received from the relay can control the transceiver.
relay_url expert since 0.117.0
What it does
Address of the presence relay.
Default
