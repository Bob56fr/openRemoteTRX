Recherche de mise à jour impossible avertissement

Message
Recherche de mise à jour impossible : {detail}.
Causes possibles
  • Pas d'accès Internet ou GitHub injoignable
  • Limite de requêtes de GitHub atteinte
  • Réponse de GitHub inattendue ou trop grande
  • Adresse non https://
Que faire
Vérifier la connexion Internet ; nouvel essai automatique dans 24 h (ou menu 10, « Chercher maintenant »).
Ce que fait la station
nouvel_essai
Alerte ntfy
non par défaut
Depuis la version

Update check failed warning

Message
Update check failed: {detail}.
Possible causes
  • No Internet access or GitHub unreachable
  • GitHub rate limit reached
  • Unexpected or oversized GitHub answer
  • Non-https address
What to do
Check the Internet connection; automatic retry in 24 h (or menu 10, "Check now").
What the station does
nouvel_essai
ntfy alert
no by default
Since version
0.123.0
