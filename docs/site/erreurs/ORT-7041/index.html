Fichier de clés du monitoring illisible erreur

Message
Monitoring : fichier de clés {fichier} illisible ({detail}) ; le module ne démarre pas.
Causes possibles
  • Fichier monlink.key abîmé ou tronqué
  • Fichier d'une autre version (format inconnu)
  • Droits de lecture insuffisants
Que faire
Restaurer le fichier depuis une sauvegarde ; à défaut, le supprimer : une nouvelle identité est créée et chaque liaison est à refaire.
Ce que fait la station
nouvel_essai
Alerte ntfy
non par défaut
Depuis la version
0.159.0

Monitoring key file unreadable error

Message
Monitoring: key file {fichier} unreadable ({detail}); the module does not start.
Possible causes
  • monlink.key damaged or truncated
  • File from another version (unknown format)
  • Insufficient read rights
What to do
Restore the file from a backup; otherwise delete it: a new identity is created and every link must be set up again.
What the station does
nouvel_essai
ntfy alert
no by default
Since version
0.159.0
