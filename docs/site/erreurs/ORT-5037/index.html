Réglages du coupleur du poste à revoir avertissement

Message
Réglages du coupleur du poste à revoir à la connexion de {client} : {reglages}. Sans eux, pas d'accord automatique à la prise d'émission sur une nouvelle fréquence : émission à vos risques.
Causes possibles
  • Accord à la prise d'émission (PTT Start) à l'arrêt dans le menu du coupleur
  • État du coupleur commun à toutes les bandes ([TUNER] Switch = Manual)
Que faire
Régler le menu du coupleur sur le poste (IC-7300MK2 : SET > Function > Tuner) ; la station ne le change jamais.
Ce que fait la station
rien d'automatique
Alerte ntfy
non par défaut
Codes du protocole
tuner_settings
Depuis la version
0.210.0

Rig tuner settings to be checked warning

Message
Rig tuner settings to be checked when {client} connected: {reglages}. Without them, no automatic tuning when transmitting on a new frequency: transmit at your own risk.
Possible causes
  • Tuning on transmit (PTT Start) off in the tuner menu
  • Tuner state common to all bands ([TUNER] Switch = Manual)
What to do
Set the tuner menu on the rig (IC-7300MK2: SET > Function > Tuner); the station never changes it.
What the station does
nothing automatic
ntfy alert
no by default
Protocol codes
tuner_settings
Since version
0.210.0

Tuner-Einstellungen des Transceivers zu überprüfen Warnung

Meldung
Tuner-Einstellungen des Transceivers bei der Verbindung von {client} zu überprüfen: {reglages}. Ohne sie keine automatische Abstimmung bei der Tastung auf einer neuen Frequenz: Senden auf eigenes Risiko.
Mögliche Ursachen
  • Abstimmung bei der Tastung (PTT Start) im Tuner-Menü ausgeschaltet
  • Tuner-Zustand für alle Bänder gemeinsam ([TUNER] Switch = Manual)
Was zu tun ist
Stellen Sie das Tuner-Menü am Transceiver ein (IC-7300MK2: SET > Function > Tuner); die Station ändert es nie.

nichts Automatisches
ntfy-Alarm
standardmäßig nein

Ajustes del acoplador del equipo a revisar aviso

Mensaje
Ajustes del acoplador del equipo a revisar al conectarse {client}: {reglages}. Sin ellos, no hay sintonía automática al conmutar a TX en una frecuencia nueva: transmisión bajo tu responsabilidad.
Causas posibles
  • Sintonía al conmutar a TX (PTT Start) desactivada en el menú del acoplador
  • Estado del acoplador común a todas las bandas ([TUNER] Switch = Manual)
Qué hacer
Ajusta el menú del acoplador en el equipo (IC-7300MK2: SET > Function > Tuner); la estación nunca lo cambia.
Qué hace la estación
nada automático
Alerta ntfy
no por defecto
